# React UI Framework Comparison

6 つの React UI フレームワークを同じコンポーネント仕様で実装し、Storybook 上で横並び比較できるデモです。

## Frameworks

| Framework | Version |
|-----------|---------|
| Ant Design | v6 |
| Chakra UI | v3 |
| Mantine | v8 |
| MUI (Material UI) | v7 |
| Radix Themes | v3 |
| shadcn/ui | v4 |

## Components

Button, Card, DatePicker, Dialog, Icon, Input, Table, Tabs, Typography

## Getting Started

```bash
bun install
bun run storybook
```

Storybook が `http://localhost:6006` で起動します。

## Scripts

| Command | Description |
|---------|-------------|
| `bun run storybook` | Start Storybook dev server |
| `bun run build-storybook` | Build static Storybook |
| `bun run lint` | Lint with Biome |
| `bun run format` | Format with Biome |
